# 货盘展示网站（szqz.github.io） 跨境货盘批次目录，客户可按「国家/仓」和「品类」筛选，点进批次看详情、咨询。 > 纯展示，不交易不下单。 ## 功能 - 批次卡片列表（封面 / 批次号 / 国家 / 品类 / 件数） - 国家筛选：美国 · 英国 · 德国 · 法国 - 品类筛选：服装 · 家具 · 家居 · 日用 · 装饰 · 配件 - 两个维度可单独选，也可叠加（如「美国 + 服装」） - 批次详情页（多图 / 描述 / 复制微信咨询） - 移动端优先，微信里可直接打开 ## 目录结构 szqz.github.io/ ├── index.html # 列表 + 筛选（首页） ├── detail.html # 批次详情页 ├── config.js # 数据源地址（如有） └── README.md ## 本地预览 1. 下载仓库：`git clone https://github.com/Hazeh22/szqz.github.io.git` 2. 进入文件夹，双击 `index.html` 用浏览器打开 3. 按 F12 打开控制台，确认无报错、筛选正常 ## 部署（GitHub Pages） 1. 把 `index.html.txt` 重命名为 `index.html` 2. 推送到本仓库 `main` 分支 3. 仓库 Settings → Pages → Source 选 `main` 分支 / 根目录 4. 访问 https://hazeh22.github.io/szqz.github.io/ 查看 5. 改完代码推送到 main 分支，GitHub Pages 会自动重新部署（约 1 分钟） ## 数据源 批次数据存在 `config.js`（或后续接 Supabase / 凡科）。 字段示例： batchNo: "US-2026-001", country: "美国", warehouse: "洛杉矶仓", categories: ["服装", "家居"], totalQty: 1200, cover: "图片地址", images: ["图1", "图2"], desc: "整批清货，混装，服装占比60%", status: "在售" ## 筛选逻辑 - 只选国家：列出该国所有批次 - 只选品类：跨国家列出该品类 - 国家 + 品类叠加：取交集 ## 注意事项 - 文件名必须是 `index.html`，不能是 `.txt` - 访问走 HTTPS，HTTP 会被浏览器拦截 - 图片建议压到 200KB 以内，加载更快 - 国内微信打开 GitHub Pages 偶有慢，正式发客户建议套 Cloudflare 或迁国内托管 ## 更新记录 - 2026-11-10 初始化：列表页 + 国家/品类筛选 + 详情页 + 咨询按钮
